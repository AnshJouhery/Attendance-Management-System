# 📸 Face Recognition Attendance Management System

🚀 A smart attendance management system developed using Python, OpenCV, and the Face Recognition library to automate attendance tracking through real-time facial recognition.

The system captures live video from a webcam, identifies registered individuals, automatically records attendance with date and time stamps, prevents duplicate entries for the same day, and stores images of unrecognized faces for review. This solution helps reduce manual effort and improves the efficiency of attendance management.

## ✨ Features

✅ Real-Time Face Detection & Recognition
✅ Automatic Attendance Recording
✅ Date & Time Based Logging
✅ Duplicate Entry Prevention
✅ Unknown Face Detection & Storage
✅ CSV-Based Attendance Management
✅ Webcam Integration
✅ Performance Monitoring (FPS Display)

## 🛠️ Technologies Used

🐍 Python
📷 OpenCV
👤 Face Recognition Library
📊 NumPy
📁 CSV File Handling

## 🎯 Objective

To automate attendance tracking using facial recognition technology, reducing manual work and improving attendance accuracy.
